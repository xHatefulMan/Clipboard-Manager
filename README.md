# Clipboard Manager

A lightweight C# WinForms app that automatically saves everything you copy to your clipboard and lets you search, preview and re-copy any entry instantly.

> The application interface is in French.

## Features

### Clipboard history
- Automatically saves up to **500 clipboard entries**
- Displays the **date, time, and character count** of each entry
- **Preview** long entries with the 👁️ button
- **Re-copy** any entry instantly with the **Copier** button
- **Delete** individual entries or clear all at once

### Search
- Real-time **search bar** to filter through your clipboard history

### Options
- **Auto-launch at Windows startup** in the background
- **Auto-delete entries older than 30 days**
- **Reduce to tray** — runs silently in the background

---

## Usage

1. Download `ClipboardManager.exe` from the [Releases](https://github.com/xHatefulMan/Clipboard-Manager/releases) page
2. Run it — no installation needed
3. Copy anything as usual — it gets saved automatically
4. Open the app to search and re-copy any previous entry
5. Click **Réduire** to minimize it to the system tray
